# Agent Context System (GCC + OneContext) — Focused Roadmap

**Part of v1 Major Release**  
**Owner**: Context Team (coordinated by Grok)

## Wave 1 (Current)
- Core GCC filesystem model + commit/branch/merge tools
- Trajectory capture adapter in run-agent-step
- Basic share token generation + import

## Wave 2
- ContextController + ContextInjector
- 9 context tools fully registered
- SDK context module + RunOptions.context

## Wave 3
- Team-shared context
- Three-way merge UI
- "Continue anywhere" end-to-end flow

**Success Metric**: User can checkpoint a complex swarm session, branch it, share the token, and resume on another machine with full history.
